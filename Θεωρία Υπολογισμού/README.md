# Οργάνωση Φακέλου

Στον φάκελο αυτό, περιέχεται το παρόν README.md αρχείο **και** ο φάκελος "Ενισχυτικό Υλικό", ο οποίος για τώρα πιθανώς να συντελείται από κάθε ενισχυτικό μάθημα που γίνεται. Συγκεκριμένα, παρατίθενται σε επόμενες παραγράφους οι δομές των επιμέρους μαθημάτων.

## 1ο Μάθημα

Για το 1ο μάθημα , θα βρεθούν 2 υποφάκελοι "appendices" και "slides". Το "appendices" αφορά στα παραρτήματα (Xournal κατά την διάρκεια του μαθήματος και εξτρα αποδείξεις) ενώ το "slides" στις διαφάνειες που φτιάξαμε για το μάθημα αυτό.

  
> **Σημείωση:** Εντός του φακέλου "slides" έχουμε και τον φάκελο "source". Ο φάκελος "source" συνίσταται από το αρχείο .tex που είναι το κυρίως κείμενο με άλλα διαγράμματα ή αρχεία που φορτώνει (π.χ. τα .eps αρχεία συντελούν αρχεία γραφικών που μπορούν να φορτωθούν μέσω $\LaTeX$.
